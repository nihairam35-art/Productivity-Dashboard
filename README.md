# Productivity Dashboard

An interactive dashboard built with Streamlit to analyze how daily habits (study, sleep, screen time) impact productivity.

## Features
- Study vs Productivity analysis  
- Screen Time vs Productivity insights  
- Key metrics (study, sleep, productivity)  
- Interactive filtering  

## Tech Stack
Python • Streamlit • Pandas • Matplotlib  

##  Run Locally
pip install streamlit pandas matplotlib  
streamlit run dashboard.py
